## 现场教训

悬空阶段之间不能断力矩，否则重力会使关节下垂并破坏下一阶段的起点。实际 commissioning 应在一个受监控序列内持续保持力矩，最后先回到有支撑的停放位，再断力矩。

完整机器可读记录见本目录 JSON，特别是 `production_low_height_observation.json` 与 `production_precision_compensation.json`。数值来自舵机读回日志；低位和视觉对准结论包含明确标注的操作者现场观察。
