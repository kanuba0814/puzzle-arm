# 系统底层算法链（坐标变换全栈定义）

> 2026-07-31 重推导定稿版。机械臂与A4工作台由3D打印固定件刚性连接，
> 所有外参为**一次性常量**，标定一次终身有效（除非拆装固定件）。
> 本文档是唯一的算法权威定义，代码实现必须与此一致。

## 0. 变换链总览

```
                      正向执行链路
 像素(u,v) ──L0──> 世界(wx,wy) ──L1──> 臂系(ax,ay,az) ──L3──> 关节角°
      │                                                        │
      │                  验证回读链路                          ▼
 像素(u,v) <──L0⁻¹── 世界 <──L1⁻¹── 臂系 <──L2 FK── 关节角 <──L4⁻¹── 舵机raw
                                                        │
                                              (J5由L5碎片姿态决定)
                                              (z高度由L6任务层决定)
```

| 层 | 名称 | 输入→输出 | 实现 |
|---|---|---|---|
| L0 | 单应映射 | 像素 ↔ 世界mm | `homography_1440.npy` / `homography.npy`(720p) |
| L1 | 刚体外参 | 世界 ↔ 臂系平面 | `motion_planner.world_to_arm/arm_to_world` |
| L2 | 正运动学 FK | 关节角 → 臂系xyz | `kinematics.forward_kinematics` |
| L3 | 逆运动学 IK | 臂系xyz+腕角 → 关节角 | `kinematics.inverse_kinematics` |
| L4 | 舵机映射 | 关节角° ↔ raw[0,4095] | `kinematics.deg_to_servo/servo_to_deg` |
| L5 | 姿态对齐 | 碎片世界朝向 → J5 | `motion_planner.world_angle_to_arm` |
| L6 | 任务高度 | 世界z → 臂系z | config TABLE/PICK/APPROACH_Z |

## 1. 坐标系定义

### 1.1 像素系 (u,v)
相机原图坐标，原点左上，u右v下。两个分辨率共用一套单应：
- 标定通道 2560×1440：`homography_1440.npy`
- 生产通道 1280×720：`homography.npy` = `diag(0.5,0.5,1) · H1440`

### 1.2 世界系 (wx,wy,wz) —— 纸面锚定
- **原点**：A4纸左下角（页头朝上读向），即图像中纸的**右上角（靠臂侧）**
- **wx**：0→210mm（读向左→右；图像中从右向左）
- **wy**：0→297mm（读向下→上；图像中从上向下）
- **wz**：纸面为0，向上为正
- 分界线 wy=148.5；下半区中心(105,74.25)=装配区，上半区中心(105,222.75)=碎片源区
- **锚定物**：打印在纸上的ChArUco网格。纸动=世界系动，臂不动 → 换纸后只需保证纸贴住固定件基准

### 1.3 臂系 (ax,ay,az)
- **原点**：J1（底座旋转）轴在桌面上的投影点
- **ax**：J1=0°时臂平面指向；**az**：桌面为0向上
- 平面极坐标 (r,z)：r=√(ax²+ay²)
- 连杆（官方URDF解算，so101_new_calib.urdf）：
  - **L1=116.6**（桌面→肩J2轴高）
  - **L2=116.0**（肩J2→肘J3轴距）
  - **L3=135.0**（肘J3→腕J4轴距）
  - **L4=98.1**（腕J4→磁铁面 = URDF腕结构61.1 + 电磁铁实测37）
- 结构说明：肘/腕轴在臂平面外侧偏18.3mm、腕部回到中平面，平面模型误差<1mm，忽略

### 1.4 关节角约定（软件约定，非URDF约定）
- **J1** 底座旋转：0=臂系ax方向，逆时针为正（俯视），限位±103°
- **J2** 肩俯仰：0=大臂水平向前，上抬为正，限位-21~82°
- **J3** 肘俯仰：0=小臂与大臂同线，折叠为负，限位-177~2°
- **J4** 腕俯仰：相对角，j4 = 绝对腕角θw - j2 - j3，限位-98~100°
- **J5** 腕旋转：0=标定零位，限位-254~88°

## 2. L0 单应映射（像素↔世界）

```
[wx]         [u]        world_px_homography: H(3×3)
[wy] = H⁻¹ · [v]  （齐次归一化）
[ 1]         [1]
```
- **标定**：`calibrate_camera.py --desk-only`，锚点帧70个ChArUco角点超定拟合
- **角点世界坐标**：由PDF几何+实测边距推出
  - 网格实测格边 21.12mm（标称22，打印缩放s=0.96）
  - 网格→纸边边距（S/V剖面实测±1.3）：左19 上19 下47 右22
  - config: `CALIB_SQUARE_BIG_MM=21.12`, `CALIB_PAPER_MARGIN_OVERRIDE=(19.0, 18.3)`
- **精度**：RMS 0.083mm / max 0.33mm；相邻角点21.120±0.052mm
- **判定**：换相机/动相机位置 → 必须重标；只动纸 → 不用（纸即世界）

## 3. L1 世界↔臂系（刚体2D变换）

```
臂→世界:  [wx]   [cosθ  -sinθ] [ax]   [tx]
          [wy] = [sinθ   cosθ]·[ay] + [ty]
世界→臂:  a = R(-θ)·(w - t)
```
- 参数：`ARM_BASE_X/Y`（=tx,ty，J1轴的世界坐标）、`ARM_BASE_ROT_DEG`（=θ，臂系→世界旋转角）
- **一次性常量**（3D打印固定件保证），由 `tools/calibrate_base_world.py` 触点标定求解：
  手扶末端碰N≥3个纸面已知点，采舵机raw→FK得臂系坐标，与世界坐标做
  相似变换最小二乘（解θ,tx,ty），输出残差+尺度诊断|W|/|A|（应≈1.000）
- **诊断**：残差>3mm或尺度偏离1.000超2% → FK链（连杆/舵机映射）有错

## 4. L2 正运动学 FK

```
r  = L2·cos(j2) + L3·cos(j2+j3) + L4·cos(j2+j3+j4)
z  = L1 + L2·sin(j2) + L3·sin(j2+j3) + L4·sin(j2+j3+j4)
ax = r·cos(j1),  ay = r·sin(j1)      (角度均为度)
```
- j4按1.4节为相对角；j2+j3+j4=绝对腕角θw

## 5. L3 逆运动学 IK（解析解）

输入 (ax,ay,az, θw绝对腕角, j5)：
```
j1    = atan2(ay, ax)
r     = √(ax²+ay²)
r'    = r - L4·cos(θw)            # 腕轴点平面半径
z'    = az - L1 - L4·sin(θw)      # 腕轴点相对肩轴高度
D     = √(r'²+z'²)                # 肩→腕轴距
可达性: |L2-L3|+1 ≤ D ≤ (L2+L3)-1
j3    = -acos((D²-L2²-L3²)/(2·L2·L3))   # 肘下折支（负角支）
j2    = atan2(z',r') - atan2(L3·sin j3, L2+L3·cos j3)
j4    = θw - j2 - j3
最后:  5关节软件限位检查
```
- **审计**：FK→IK→FK 431组姿态往返误差 0.000mm（精确解析互逆）

## 6. L4 舵机映射（STS3215，12位磁编）

```
raw = clip(2048 + OFFSET[sid] + SIGN[sid]·deg·(4096/360), 0, 4095)
deg = SIGN[sid]·(raw - 2048 - OFFSET[sid]) / (4096/360)
```
- 全关节1:345减速比（Follower统一），12位=4096/360°线性，**无关节差异**
- `SERVO_LIMITS` 仅安全钳位不参与缩放；超出限位的输入被钳到限位（设计行为）
- SIGN/OFFSET 实物标定（calibrate_arm.py lerobot式），J2方向曾误记后修正，
  最终由触点标定尺度诊断背书

## 7. L5 碎片姿态对齐

```
J5 = wrap(piece_world_angle - ARM_BASE_ROT_DEG)
```
- 碎片世界朝向角由CV（detect_pieces）给出；基座旋转已被L1吸收，只需移项

## 10. 可达域实测结论（近似基座-58,148.5下扫描）

| 工况 | 纸面覆盖率 | 瓶颈 |
|---|---|---|
| 贴面z=5 腕-90° | 82% | 远角臂展（D≤250） |
| 贴面z=5 腕-70° | **96%** | 仅剩纸远角条带 |
| 悬停z=50 腕-90° | 64% | 近基座点J2上限 |

**规划含义**：远端抓取/放置用腕-70°斜接近；悬停高度按区域自适应
（远区可降低悬停高度或斜腕）；正式流水线需做逐任务可达性预检并选腕角。
