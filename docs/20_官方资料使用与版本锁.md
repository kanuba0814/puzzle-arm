# 20 官方资料使用与版本锁

## 来源层级

1. 赛题 PDF 原文；
2. 官方稳定版本文档和固定 tag/commit 源码；
3. 官方器件产品页或规格书；
4. 论文原文；
5. 社区资料只可作为排障线索，不可作为关键参数依据。

## 冻结版本

- LeRobot：`v0.6.0`
- LeRobot 对应官方发布 commit：`30da8e687a6dfc617fcd94afc367ac7071c376ce`
- Python：LeRobot v0.6.0 的 PyPI 元数据要求 Python >= 3.12；实际环境需按本地 wheel 可用性验证。
- OpenCV：文档基线 `4.13.0`；实际安装版本必须记录并在冻结后停止升级。
- Raspberry Pi：使用官方 Raspberry Pi 5 产品简报和 27W 电源简报。

## 动态来源处理

SO-ARM100 官方仓库的 `main` 会变化。以下内容必须在本地克隆后记录 commit：

- STL/STEP；
- URDF；
- 相机安装件；
- BOM 与装配说明。

没有记录 commit 的 `main` 文件只能用于初步参考，不能作为冻结后的唯一恢复来源。

## 未镜像但已锁定链接

LeRobot v0.6.0 在线文档、固定 tag 源码、OpenCV 在线文档和 SO-ARM100 仓库因发布形态为动态网页/源码树，保存精确 URL 和版本信息，不把不完整网页抓取伪装为离线镜像。

## 更新规则

- 比赛分支冻结后不得升级依赖。
- 需要更新来源时，先复制 `sources.lock.json`，再修改版本并重新跑全部验收。
- 任何来自社区的参数必须在实物上复测后才能写入 `configs/parameter_registry.yaml` 的 `measured` 区域。
