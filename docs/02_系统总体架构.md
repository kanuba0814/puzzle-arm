# 02 系统总体架构

## 运行时数据流

```text
CameraService
  -> RectifiedFrame
  -> VisionService
       -> PieceObservation[]
       -> WorkspaceState
  -> PuzzleSolver
       -> PlacementPlan[]
  -> Supervisor
       -> MotionGoal
  -> DeterministicMotion
       -> IK + JointTrajectory
       -> Pregrasp / Preplace
  -> ACTLocalPolicy (可选)
       -> 5D joint correction chunk
  -> SafetyFilter
  -> SO101Follower5D
  -> MagnetController
  -> VisionVerify
  -> Success / Retry / Replan
```

## 进程边界

### CameraService

- 固定曝光、白平衡和焦距。
- 采集全分辨率画面并附单调时钟时间戳。
- 只保留最新帧，禁止旧帧积压。

### VisionService

- 去畸变、透视校正、背景分割。
- 输出碎片轮廓、桌面坐标、方向、最大内接圆抓取点和置信度。
- 机械臂运动时可暂停全局求解，但相机服务继续运行。

### PuzzleSolver

- 自备题使用模板身份和预定义目标位姿。
- 白色现场题使用多边形边匹配、外边约束、排列/旋转枚举与碰撞检测。
- 扑克牌题在几何候选上增加纹理接缝评分。

### Supervisor

- 唯一拥有任务状态转换权。
- 负责超时、重试、回退、完成指示。
- ACT、视觉或机械控制不得自行切换全局任务阶段。

### DeterministicMotion

- 解算预抓取、抓取、预放置和放置位姿。
- 所有横向移动在 `Z_safe` 完成。
- 输出平滑关节目标并接受安全过滤。

### ACTLocalPolicy

- 只在 Supervisor 明确进入局部技能状态时运行。
- 输入局部图像与 5 维关节状态；可选输入目标误差和技能 ID。
- 输出 5 维短动作块或残差动作。
- 超时或异常即退出，不允许阻塞机械臂控制线程。

### MagnetController

- Raspberry Pi `/dev/gpiochip0` 的 BCM GPIO17 只驱动继电器控制输入，不直接驱动电磁铁线圈。
- 当前继电器为低电平触发；GPIO17 稳定输出 3.3 V 高电平是默认关闭状态。
- 具有默认关闭和急停关闭；吸合后保持到调用方显式关闭，不再自动按 10 秒断电。
- 线圈电气参数、温升和实测连续通电能力仍为 `UNKNOWN`，调用方必须负责关闭。
- 吸取和释放动作由 Supervisor 通过 `set_enabled(bool)` 触发。

## 降级路径

- ACT 不可用：使用 IK 直接到 `Z_pick/Z_place`。
- 拼图求解失败：保留已识别状态，尝试重新拍照；不得盲动。
- 抓取失败：重新计算抓取点，最多重试规定次数。
- 放置偏差：重新识别所有碎片并生成新计划。
