# 24 通用视觉与拼图求解器设计

## 边界与安全

`vision.observe_pieces` 只输出带坐标系、SHA256 来源和单调时间戳的观察；`puzzle.solve_puzzle` 是不读文件、不控制设备的纯函数。通用视觉和纹理 feature flag 默认关闭。磁头 footprint、正式 table 到 robot 标定、PICK/PLACE 高度均为 `UNKNOWN`，因此观察器不会宣称可抓取。

## 观察 seam

白色/印刷 profile 在 rectified A4 上半源区使用背景建模和三个相邻阈值投票。粘连或无法拟合 3--5 边简单多边形返回拒绝；金属暗面返回 `VISION_SURFACE_MISMATCH`。物理像素轮廓与毫米虚拟多边形同时保留。圆角恢复只允许显式 profile 开启，白色 profile 默认关闭。

## 求解 seam

边候选包含完整、端点锚定和内部 offset 部分边；位姿仅允许正向 SE(2)。所有分项为 lower-is-better penalty。未冻结的歧义间隔不授权多解：返回 `SOLVER_AMBIGUOUS`，不带计划；预算耗尽返回 `SOLVER_TIMEOUT`。

## UNKNOWN 与 Gate C

题面未确认纸面朝上、可见间隙、碎片数量下限及目标尺寸文字的方向解释；代码选择拒绝而不镜像猜测。Gate C 唯一口径为离线白色盲测 ≥18/20，且实机连续 5 次成功；合成结果不能替代实拍/Pi/盲测证据。
