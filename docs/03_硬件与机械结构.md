# 03 硬件与机械结构

## 核心硬件

- Raspberry Pi 5 8GB，独立 5.1 V / 5 A 供电，主动散热。
- SO-101 follower，保留 ID 1-5 五个 STS3215，移除 ID 6 夹爪舵机。
- 顶置 UVC 相机或 Raspberry Pi Camera；首版只使用一路。
- 电磁吸头、MOSFET、续流器件、独立电源支路。
- 声光完成指示和物理急停/总电源断开。

## 工作区布局

- 机械臂基座固定在 A4 纸长边附近，目标是覆盖上半待取区与下半拼图区。
- 相机固定在整个 A4 工作区正上方，镜头轴尽量垂直纸面。
- 机械臂回零姿态不得遮挡 A4 纸。
- 横向运动路径不得碰到相机支架和纸张边缘固定件。
- A4 纸必须固定，测试过程中不得滑动。

## 末端姿态

- 电磁铁工作面保持近似垂直桌面法向。
- 腕部旋转轴负责碎片平面角度。
- 末端增加 3-8 mm 轴向浮动，吸取时避免用舵机刚性压桌面。
- 增加机械顶出环或剥离结构解决剩磁。

## 结构误差控制

- 底座用螺栓固定到厚板或铝型材，不使用临时胶粘作为最终方案。
- 关节到目标点的最后接近方向保持一致，降低齿隙方向反转误差。
- 机械臂大范围动作低加速度，持片时进一步降低速度。
- 先测工作空间，再确定纸张和基座位置，不依赖理论可达范围。

## 供电隔离

- Pi、电机总线和电磁铁分支供电容量分别核算。
- Pi 与执行器共地，但避免电磁铁回流经过 Pi 地线。
- 电磁铁和舵机电源入口均加保险或限流保护。
- GPIO 上电默认低电平，软件崩溃不得导致磁铁持续通电。

## 必须记录的实物信息

- 每个 STS3215 标签的完整型号，特别区分 7.4 V C001 与 12 V C018。
- 舵机电源实际电压和限流值。
- 电磁铁额定电压、线圈电阻、稳态电流、表面温升。
- 相机型号、分辨率、焦距、设备路径。
- 机械臂基座到 A4 纸坐标原点的实际测量值。
