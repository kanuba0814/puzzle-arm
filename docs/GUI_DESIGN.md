# E题拼图装置 GUI 设计文档

更新时间：2026-07-31  
适用项目：SO-ARM101 + 树莓派 + 本地相机的 E题拼图装置  
对应界面：`gui_fb.py`（pygame / SDL2 / kmsdrm）

---

## 1. 设计目标

GUI 从“调试控制台”升级为：

> **比赛一键运行控制台 + 系统标定向导 + 手动调试工具**

设计重点：

1. 符合赛题“一键启动、中途无人工干预”的流程。
2. 120 秒比赛计时清晰可见。
3. 纯白碎片和扑克牌碎片使用不同比赛配置。
4. 运行完成后提供声、光和屏幕提示。
5. 保留现有标定、手动控制、日志、急停等全部功能。
6. 树莓派 OS Lite 无桌面环境下直接显示，不依赖 X11。

---

## 2. 赛题约束到 GUI 的映射

| 赛题要求 | GUI 设计响应 |
| --- | --- |
| 摄像头先遮挡，随机摆放碎片后一键启动 | 独立“比赛模式”，检查通过后单个“一键开始比赛”按钮直接启动 |
| 启动后中途无人工干预 | 自动运行期间锁定标定、手动控制和设置页面，仅保留“中止任务”和“急停” |
| 总时间不超过 2 分钟 | 大号计时器、剩余时间、阶段耗时、110 秒警告、120 秒超时 |
| 扑克牌任务时间越短越好 | 结果页突出总耗时，运行记录保存每次耗时 |
| 碎片数量不大于 4 片 | 显示“已检测 x/4、已放置 x/4、当前碎片 x” |
| 上半区移动到下半区 | 相机画面叠加 A4 边界、分界线、目标区域 |
| 纯白碎片和扑克牌碎片 | 任务配置拆分为任务1纯色、任务2A白色、任务2B扑克牌 |
| 拼接完成后声光提示 | 蜂鸣器、LED、绿色完成页三重提示 |
| 正常室内照明 | 自检和诊断页显示亮度、清晰度、曝光、角点/碎片检测情况 |
| 碎片位置正确、不重叠 | 运行页显示碎片轮廓、目标矩形、当前抓取和放置状态 |

## 3. 技术栈和运行方式

继续使用当前技术栈：

- Python 3
- pygame / pygame-ce
- SDL2 `kmsdrm`
- 树莓派 OS Lite 纯 tty 直显
- 本地 UVC 相机标定
- 本地舵机总线

```bash
bash tools/start_gui_fb.sh
```

开发机窗口调试：

```bash
python3 gui_fb.py --window 800x480
```

## 5. 全局界面规范

### 5.1 顶部常驻状态栏

保留现有状态项：

- 连接：已连接 / 未连接
- 模式：模拟 / 硬件
- 力矩：使能 / 失能
- 电磁铁：吸合 / 释放
- 标定：已标定 / 未标定
- 任务：空闲 / 标定中 / 检测中 / 求解中 / 执行中 / 完成 / 错误
- J1–J5 当前角度

右上角常驻红色按钮：

```text
[急停]
```

急停行为不变：

- 设置任务中止标志
- 关闭电磁铁
- 释放全部舵机力矩
- 状态改为空闲
- 记录 ERROR 日志

### 5.2 触摸屏规范

适配 800×480：

- 常规按钮高度不小于 44 px
- 主要按钮高度不小于 56 px
- “一键开始比赛”高度不小于 72 px
- 不可用按钮置灰
- 运行期间禁止隐藏手势
- 危险操作使用红色或橙色
- 正常操作使用蓝色或绿色

## 6. 页面设计

### 6.1 开机自检页 `boot`

检查项目：

- 舵机串口连接
- 电磁铁 GPIO
- 本地 UVC 相机
- 中文字体
- OpenCV ArUco
- `homography.npy`
- `arm_base.json`
- 蜂鸣器 / LED
- 自动任务后端可用性

检查结果分三类：

- 通过：绿色
- 警告：橙色，不影响进入主界面
- 失败：红色，禁止“一键开始比赛”

按钮：

- 重新自检
- 进入主界面
- 去系统标定

---

### 6.2 主界面 `main`

采用 2×2 大入口：

```text
┌──────────────────────┬──────────────────────┐
│ 比赛模式             │ 系统标定             │
│ 一键自动拼图         │ 相机/机械臂标定       │
├──────────────────────┼──────────────────────┤
│ 手动调试             │ 运行记录/日志         │
│ 关节/末端/电磁铁      │ 日志/历史/导出        │
└──────────────────────┴──────────────────────┘
```

原“自动控制”更名为“比赛模式”，原有自动功能保留在其中。

---

### 6.3 比赛准备页 `auto`

#### 任务配置

提供三个大任务卡片：

1. **任务1：自备纯色**
   - 固定 4 片
   - 纯色碎片
   - 对应后端模式 `task1`

2. **任务2A：现场白色**
   - 数量不大于 4 片
   - 白色纸片
   - 对应后端模式 `task2_white`

3. **任务2B：现场扑克牌**
   - 数量不大于 4 片
   - 白底扑克牌图案
   - 对应后端模式 `task2_card`

兼容旧模式 `task2`，语义等同于扑克牌任务。

#### 比赛前检查清单

- 机械臂已连接
- 力矩状态正常
- 电磁铁可用
- 工作区标定有效
- 基座标定有效
- 相机画面可用
- 声光提示可用
- 当前任务配置合法

#### 一键开始

```text
[              一 键 开 始 比 赛              ]
```

交互规则：

- 检查失败时按钮禁用或点击后给出明确原因。
- 点击后立即启动，不做二次确认。
- 启动后进入 `run` 页面。
- 提示“请立即移除摄像头遮挡”。

### 6.4 自动运行页 `run`

布局建议：

```text
┌──────────────────────────────┬───────────────┐
│                              │ 00:37.2       │
│ 最新相机画面 / 视觉状态       │ 剩余 82.8 s   │
│                              │               │
│ A4边界/分界线/目标区域        │ 检测：4/4     │
│ 碎片轮廓/当前目标             │ 放置：2/4     │
│                              │ 当前：碎片3   │
│                              │               │
│                              │ 当前阶段      │
│                              │ 执行搬运      │
│                              │               │
│                              │ [中止任务]    │
└──────────────────────────────┴───────────────┘
```

运行阶段：

```text
初始化 → 标定加载 → 碎片检测 → 拼图求解 → 执行搬运 → 完成校验
```

运行期间锁定：

- 系统标定
- 手动关节控制
- 末端 XYZ 控制
- 设置和清空日志

允许操作：

- 查看运行画面
- 中止任务
- 急停

时间规则：

- 0–90 秒：绿色
- 90–110 秒：橙色
- 110–120 秒：红色
- 120 秒未完成：超时失败并安全停止

---

### 6.5 运行结果页 `result`

成功时：

```text
拼图完成

总耗时：83.6 秒
检测碎片：4/4
成功放置：4/4
任务模式：任务2B 扑克牌

[返回比赛准备] [查看日志] [再次运行]
```

失败时显示明确原因：

- 未检测到碎片
- 检测数量不足
- 拼图求解失败
- 机械臂初始化失败
- 搬运任务失败
- 超过 120 秒
- 用户中止
- 急停

每次运行保存：

- 任务模式
- 开始和结束时间
- 总耗时
- 检测数量
- 放置数量
- 成功 / 失败
- 失败原因
- 关键日志

---

### 6.6 系统标定页 `calibration`

保留现有功能并改为向导式流程：

```text
① 工作区标定 → ② 释放力矩 → ③ 触点记录 → ④ 解算基座 → ⑤ 标定验证
```

#### 工作区标定

保留：

- 打开本地相机
- ChArUco 检测
- 单应矩阵计算
- 保存 `homography.npy`
- 保存 `out/calib_summary.json`

界面显示：

- 检测角点数量
- 图像清晰度
- 标定板覆盖率
- RMS 残差
- 最大残差

#### 触点标定

保留：

- 预览中点击目标点
- 释放力矩
- 手扶末端碰点
- 记录触点
- 撤销触点
- 解算基座
- 重新打开相机

新增提示：

- 已记录 `n/3` 或 `n/4`
- 触点过于集中警告
- 基座解算误差
- 成功后自动恢复力矩

---

### 6.7 手动调试页 `manual`

保留全部现有功能：

- 力矩使能 / 失能
- 电磁铁吸 / 放
- 回纸外驻车位
- J1–J5 关节步进
- 1° / 5° / 10° / 30° 步长
- X/Y/Z 末端步进
- 1 / 5 / 10 / 50 mm 步长

安全规则：

- 自动任务运行时禁用手动运动按钮。
- 力矩未使能时运动按钮置灰。
- 电磁铁状态使用醒目的颜色显示。
- 手动运动后刷新关节角和状态栏。

---

### 6.8 日志和运行记录页 `log`

保留：

- INFO / WARN / ERROR 日志
- 颜色区分
- 清空日志

新增：

- 导出日志
- 最近运行记录
- 成功 / 失败耗时统计
- 失败原因快速查看

## 7. 自动运行状态机

```text
READY
→ INIT
→ CALIBRATING
→ DETECTING
→ SOLVING
→ EXECUTING
→ DONE

任意阶段可进入：
→ ERROR
→ IDLE（用户中止）
→ ESTOP（急停）
```

状态显示映射：

| 内部状态 | 中文显示 |
| --- | --- |
| IDLE | 空闲 |
| INIT | 初始化 |
| CALIBRATING | 标定中 |
| DETECTING | 检测中 |
| SOLVING | 求解中 |
| EXECUTING | 执行中 |
| DONE | 完成 |
| ERROR | 错误 |
