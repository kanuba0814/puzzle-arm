# 04 电磁吸头设计

## 题面结论

题面没有出现“必须使用电磁铁”的要求，只规定现场碎片含约 0.3 mm 镀锌薄铁片。电磁吸取是工程选择，不是评分指定方式。

## 吸力要求

题面给出“重量不大于 30 g”，但未进一步明确该上限针对单片还是整组。为避免低估，工程验证按单次抓取对象 30 g 处理，对应重力约 0.294 N。不能使用电磁铁裸铁直接接触的标称吸力，因为实际磁路包含纸片、镀锌层、不平整；题面的 2 mm 是碎片总厚度，并不等同于磁路空气隙。应按实物纸层厚度、磁头结构和最坏表面状态制作等效试片，直接测量动态可靠性。

最低验收：

- 通过实测最坏有效间隙后吸起 30 g 保守试片；
- 机械臂以最终计划速度搬运不脱落；
- 连续 50 次吸取无过热、无明显吸力下降；
- 断电后可在 0.5 s 内通过顶出结构可靠释放。

## 结构

```text
Wrist flange
  -> axial spring/flexure
  -> electromagnet core
  -> non-magnetic ejector ring
  -> paper layer
  -> galvanized steel piece
```

## 抓取点

使用碎片掩码的距离变换最大值点，确保磁头尽可能远离边缘。若最大内接圆半径小于磁头有效半径加安全边距，该碎片不能按当前磁头方案可靠抓取，必须换更小磁头或改变吸附结构。

## 驱动

- 逻辑电平 N 沟道 MOSFET 低侧驱动。
- 线圈两端配置续流二极管或经验证的 TVS/快速释放网络。
- GPIO 串联栅极电阻并设置下拉。
- 独立保险和电流测量点。
- 连续通电设置软件最大时间。

## 状态机

吸取：

1. 到达抓取高度。
2. 低速压缩浮动机构。
3. 开启磁铁并等待固定吸附时间。
4. 垂直抬升小距离。
5. 视觉检查原位置是否已空。
6. 通过后才进入横向搬运。

释放：

1. 到达放置高度并稳定。
2. 关闭磁铁。
3. 顶出环/剥离机构作用。
4. 等待后缓慢上升。
5. 视觉检查碎片是否留在目标位置。

## 不建议首版使用

- 仅靠断电释放；
- 高频反向退磁，除非已有 H 桥和实测依据；
- 永磁铁直接吸取；
- GPIO 直接带线圈。
