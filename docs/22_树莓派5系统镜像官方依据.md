# 22 树莓派 5 系统镜像官方依据

核对日期：2026-07-29。只采用 Raspberry Pi、Debian、Hugging Face/LeRobot、PyPI 官方资料与本地固定源码。

## 冻结结论

- 目标硬件：Raspberry Pi 5 8GB、64GB microSD、官方 5.1V/5A 27W 供电、主动散热。
- OS：Raspberry Pi OS Lite 64-bit，Debian 13 Trixie，arm64。
- 官方基础镜像：`2026-06-18-raspios-trixie-arm64-lite.img.xz`。
- 官方 SHA256：`acff736ca7945e3b305f07cda4abdb870910e12634991da69783611756e381b3`；本地下载已按该值校验。
- 基础镜像实查：Debian `13.5`、Python `3.13.5`、kernel `6.18.34+rpt-rpi-2712`。
- LeRobot：`v0.6.0` / commit `30da8e687a6dfc617fcd94afc367ac7071c376ce`，要求 Python `>=3.12`。
- arm64 wheel：PyPI 元数据和实际下载确认 torch `2.7.1`、torchvision `0.22.1`、NumPy `2.2.6`、OpenCV headless `4.13.0.90` 均有兼容 aarch64 wheel。
- Feetech：`feetech-servo-sdk==1.0.0` 仅发布源码包；已在构建机转为 `py3-none-any` wheel，并纳入 SHA256 清单。
- ACT 仍是项目可选局部增强，镜像默认关闭。

## 系统依据

### Raspberry Pi OS 与首启

Raspberry Pi 官方提供 64-bit Lite 镜像和下载哈希；Trixie 镜像使用 cloud-init/Netplan/NetworkManager 首启配置。基础镜像自身包含 `rpi-resize.service` 和内核命令行 `resize`，写入更大卡后首启自动扩展根分区。

官方来源：

- <https://downloads.raspberrypi.com/raspios_lite_arm64/images/raspios_lite_arm64-2026-06-19/>
- <https://www.raspberrypi.com/software/operating-systems/>
- <https://www.raspberrypi.com/documentation/computers/os.html>
- <https://www.raspberrypi.com/news/cloud-init-on-raspberry-pi-os/>

### SSH 与 headless

官方支持 Imager 预置、bootfs 空文件 `ssh`、`userconf.txt` 用户密码哈希以及 cloud-init。项目镜像使用 `ssh` + `userconf.txt` 将 UID 1000 用户改名为 `epuzzle`，只部署构建时生成的 Ed25519 公钥，sshd 禁止 root 和口令登录。

官方来源：

- <https://www.raspberrypi.com/documentation/computers/getting-started.html>
- 基础镜像内 `/usr/lib/userconf-pi/userconf-service`
- 基础镜像内 `/usr/lib/raspberrypi-sys-mods/sshswitch`

### 供电、散热、GPIO 与相机

Pi 5 官方推荐 27W USB-C 供电。供电能力不足时 USB 外设预算会降低；本项目同时使用相机和机械臂 USB/串口，因此必须按 5.1V/5A 配置。主动散热及 `vcgencmd get_throttled`、温度日志属于实机验收项。

Pi Camera 有官方 libcamera/rpicam 链路。具体 UVC 相机型号、分辨率、FPS、自动参数锁定和长时间稳定性仍必须实机验证。

官方来源：

- <https://www.raspberrypi.com/documentation/computers/raspberry-pi.html>
- <https://www.raspberrypi.com/documentation/accessories/camera.html>
- `official_docs/raspberry_pi/Raspberry_Pi_5_product_brief_2026-04.pdf`
- `official_docs/raspberry_pi/Raspberry_Pi_27W_USB-C_power_supply_product_brief.pdf`

GPIO 只可驱动外部 MOSFET 栅极，不可直接驱动电磁铁。具体 GPIO line、MOSFET、续流网络、电磁铁电压/电流仍为 `UNKNOWN`；必须按实物电路台架验证。硬件栅极下拉是默认断电安全基础，软件 GPIO 不是替代品。

## 安全与离线恢复

镜像采用 Raspberry Pi OS Lite，无桌面、VNC、NoMachine、Docker 和 ROS；默认 nftables 拒绝入站，仅放行 SSH、DHCP、ICMP、mDNS。比赛 systemd 服务使用 `NoNewPrivileges`、`ProtectSystem`、`ProtectHome` 等限制，按相机、串口、GPIO 与日志目录显式放行。

镜像保存完整 wheelhouse 及逐文件 SHA256，支持断网重建 Python venv。主任务不自动启用：实物参数、udev、标定文件、Supervisor 代码未完成前，preflight 应失败并阻止机械臂动作。

## 必须实机验证

1. 每个 STS3215 完整型号、ID 1-5、实际供电电压和限流；
2. 控制板 USB VID/PID/serial 与稳定 `/dev/epuzzle-arm` udev 规则；
3. 相机型号、设备节点、曝光/白平衡/焦距、分辨率与 FPS；
4. 电磁铁 GPIO line、驱动级、续流、稳态电流、温升和最大通电时间；
5. 四个标定文件及哈希；
6. Pi 5 上 torch/OpenCV/LeRobot 实机 import、ACT p50/p95、30 分钟温度/降频；
7. 舵机总线、相机、电磁铁同时工作时无欠压、重启和 USB 掉线；
8. 完整一键状态机实现。当前仓库只有架构和插件，尚无 Supervisor 业务实现，镜像不能被表述为已完成赛题功能。
