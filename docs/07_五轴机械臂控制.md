# 07 五轴机械臂控制

## 自由度

去掉夹爪后保留：

1. shoulder_pan
2. shoulder_lift
3. elbow_flex
4. wrist_flex
5. wrist_roll

对本题可控制末端位置 x/y/z、末端俯仰和碎片平面旋转。末端滚转/偏航命名以实际 URDF 坐标为准，不能仅凭关节名假设。

## 控制层级

### 关节总线层

- 同步读取 Present_Position。
- 同步写入 Goal_Position。
- 保存时间戳、通信耗时和异常码。
- 任何写入前经过限位与步长过滤。

### 逆运动学层

- 目标为电磁铁中心，不是打印件法兰中心。
- 首选解析/数值 IK，以上一解为初值。
- 若 IK 无解，Supervisor 不得尝试随机关节动作。
- 保存多个候选解时，选择距当前关节最小且远离限位的解。

### 轨迹层

固定关键位姿：

- HOME
- Z_SAFE
- PREGRASP
- PICK
- PREPLACE
- PLACE

所有水平平移在 Z_SAFE 完成。使用三次或五次插值限制速度和加速度，不直接跳变舵机目标。

## 安全过滤

- 关节软限位和硬限位表。
- 单周期最大角度变化。
- 最大速度和加速度。
- 末端最低高度。
- 低高度时腕部旋转限制。
- 持片时最大速度缩减。
- 命令时间戳过期即丢弃。
- 急停立即停止新动作并关闭磁铁。

## 校准

- 五轴插件使用新的 robot ID 和新的标定文件。
- 不加载包含 `gripper` 的六轴标定。
- 标定完成后执行关节方向检查、零位检查、全范围慢速检查。
- 建立工作区网格误差图，用视觉测得实际末端位置。

## 基线抓放流程

在 ACT 接入前必须完成：

1. OpenCV 给出抓取点。
2. IK 到 PREGRASP。
3. 垂直下降到 PICK。
4. 开磁铁并验证。
5. 上升到 Z_SAFE。
6. 横移到 PREPLACE。
7. 调整 wrist_roll。
8. 下降、释放、抬升。
9. 视觉复核。
