## 既有件实测（boardCam.STL / camBridge.STL）

坐标系：以 STL 原始坐标为准，单位 mm。

- boardCam 整体包络：182.3（X）× 46（Y）× 241.15（Z）。
- 主立板厚 5 mm，中部开 Ø≈160 减重圆孔。
- 底部中央叉耳块：宽 35（X 73–108），深 46（Y），高 55。
- 叉口：宽 12.0（X 85.1–97.2），深约 15，半圆底 R6。
- 横向锁孔：轴沿 Y，孔心距叉耳底边约 6.0（X≈92.5，Z≈5.9），前段孔径 Ø≈9.6，后段沉孔 Ø≈17。
- camBridge：77 × 6.6 × 45 小板，下端漏斗形耳片带 Ø≈8 通孔。

叉耳意图（用户确认）：凸耳插入叉口后**防止支架本体与底座接口旋转、固定接口位置**，即顶部为防转插接座，而非俯仰铰链。±10° 俯仰微调由支架顶端肘节实现，不依赖叉耳转动。

## 总体布局

所有尺寸单位 mm；桌面为 Z=0，A4 纸面坐标沿用系统约定（X 横向、Y 纵向）。

```text
桌面 Z=0
 └─ P1 底座 Ø166.2×36，圆心即偏航轴（A4 短边外侧，边距约 5）
     └─ 偏航关节（竖直轴，接触点 Z=60，锁紧）
         └─ P3 偏航转子
             └─ P4 斜梁（前伸 230，仰角约 14°，到 Z≈129）
                 └─ P5 顶端肘节（俯仰微调 ±10°，锁紧）
                     └─ 防转凸耳 → boardCam 叉耳（销 Ø9.4 锁定）
                         └─ camBridge → MaixCAM Pro，镜头 Z=364±20，垂直向下
```

关键链式尺寸：

- 偏航接触点：Z=60（在 50–70 区间中值，可 ±10 垫片调整）。
- 顶端销孔中心：Z≈129，水平前伸 230（底座圆心到 A4 中心 = 圆盘半径 83.1 + 边距 5 + A4 半长 148.5 ≈ 237，凸耳前伸后镜头落 A4 中心上方，参数化微调）。
- 镜头高度：叉耳孔心到镜头光心距离 L_LENS ≈ 235（**保守假设**：镜头在 boardCam 顶部附近，未实测）；364 = 129 + L_LENS。±20 调节由顶端肘节两档 ±10° 与斜梁根部长孔共同实现。

## 稳定性核算（保守假设）

质量估计（**保守假设**，实物称重后更新）：

- boardCam 约 150 g（5 mm 板含 Ø160 孔，PLA 稀疏填充）。
- MaixCAM Pro + camBridge：**UNKNOWN**，按 120 g 保守取值。
- 斜梁 + 肘节 + 转子约 90 g。

绕底座边缘倾覆力矩（最不利偏航角，前伸正对 A4）：

```text
M_ot = 9.81 × [0.270 kg × (0.230-0.083) m + 0.060 kg × (0.115-0.083) m]
     ≈ 0.41 N·m
```

抗倾力矩 = M_base × 9.81 × 0.083 m。安全系数 ≥2 要求 **M_base ≥ 1.0 kg**。

配重腔设计：内径 Ø150、深 32，容积约 550 cm³。

- 干沙（约 1.5 g/cm³）仅约 820 g，连同壳体约 0.95 kg，**不足**；
- 默认方案：钢珠/钢砂填充 ≥900 g，连壳体总重 ≥1.1 kg；
- 若现场只有干沙，必须通过后述倾覆实测才允许使用。

## 零件分解

| 编号 | 零件 | 关键设计 | 打印方向 |
| --- | --- | --- | --- |
| P1 | 底座盘 | Ø166.2×36，镂空筋板壳体，配重腔 Ø150×32，中央塔柱至偏航孔 Z=60；表面刻 A4 中心线与短边对齐线 + 箭头 | 平放，无支撑 |
| P2 | 配重腔盖 | 4×M3×6 拧入底座预埋 M3 螺母孔 | 平放 |
| P3 | 偏航转子 | 下止口 Ø40×18 插入底座塔柱孔（直径间隙 0.4）；上法兰接斜梁，4×M3×6 入预埋螺母 | 立放 |
| P4 | 斜梁 | 长约 240，渐变箱形截面 30×20→20×15，纵向加强筋；根部法兰；顶端俯仰铰 | 平放床面（<256） |
| P5 | 顶端肘节 | 与 P4 圆弧长孔铰接，±10° 分度刻线，2×M3×6 夹紧；前端防转凸耳 11.8（厚）×44（长），头部 R5.9 | 平放 |
| P6 | 锁销 | 打印 Ø9.4×52，一端法兰，另一端横孔 M3×6 防退；穿 boardCam 叉耳 Ø9.6 孔 | 立放 |
| P7 | A4 定位角尺 ×2 | L 形，贴底座标记摆放 A4 | 平放 |
| P8 | 线缆夹 ×3 | MaixCAM USB 线沿斜梁固定 | 平放 |

M3×6 短螺丝约束下的统一做法：所有夹紧/连接均为「螺丝穿过 ≤2.8 mm 耳板 → 预埋 M3 螺母孔（六角对边 5.8、深 3）」，不使用需要长螺丝的贯穿结构。偏航锁紧为塔柱开口夹环 + 2×M3×6 抱紧转子止口。

可选升级（**待用户确认采购**）：M8×60 螺栓螺母替代 P6 打印销；TPU 摩擦垫片。

## 验收断言（claims，未验证前视为未通过）

几何与打印：

1. 全部零件包络位于 P1S 256×256×256 内。
2. 凸耳-叉口配合：凸耳 11.8 mm 对叉口 12.0 mm，插入顺畅且无可见晃动；锁销 Ø9.4 对孔 Ø9.6。正式打印前先打 20 mm 试片验证本机孔/轴补偿。
3. 总打印时间目标 ≤10 h（估计值，切片后更新为实测）。

整机性能（实测验收）：

1. 配重后底座总重 ≥1.0 kg；最不利偏航角下，镜头高度处施加 1 N 水平扰动不倾覆、不滑移。
2. 斜梁端部在 2.5 N 竖直载荷下挠度 ≤3 mm；扰动后图像稳定时间 ≤2 s（OpenCV 帧差验证）。
3. 镜头光心高度在 344–384 mm 范围内可调，镜头轴竖直（用单应/水平仪验证）。
4. 视野覆盖整张 A4：MaixCAM Pro 镜头 FOV 为 **UNKNOWN**，必须实拍验证四角均在画面内。
5. 偏航 360° 可转，锁紧后梁端切向 2 N 力不转动。
6. 机械臂全工作空间动作不与支架干涉：按冻结布局，肩轴（约 X=-40, Y=150）到底座塔柱（约 X=105, Y=385）水平距离约 276 mm，**保守假设**该距离大于臂展，必须实测校核并在控制软件中设置支架禁入区。

## UNKNOWN 与待确认

- MaixCAM Pro 实际质量、镜头 FOV、镜头光心在 boardCam 上的准确位置（当前 L_LENS=235 为假设）。
- 底座与 A4 短边的实际间隙（当前按 5 mm）。
- P6 销是否允许改用 M8 标准螺栓。
- 灌沙材料实际密度与可获得性（钢砂优先）。
- boardCam 后段 Ø17 沉孔的设计意图（当前仅作为销端让位处理）。

## 参数化模型与首轮断言结果（2026-02 补充）

build123d 参数化模型已建于 `mechanism/camera_stand/`（几何唯一真源 `params.py` + `parts/*.py`，构建与断言入口 `build_all.py`）。首轮全部硬断言通过，产物见 `exports/`（每零件 STL+STEP + 装配 STEP）、`reports/stand_report.json`、`renders/` 三视图。

相对上文方案的设计细化：

- 底座拆为两件（P1a 桶 + P1b 顶板），避免 Ø150 配重腔顶面搭桥无法打印。
- 顶部接口定为 **插榫 11.8×11.8 + P6 C 形夹箍外抱叉耳块**；boardCam 底部 Ø9.6/Ø17 孔位不使用（意图待确认，保留升级可能）。
- 夹紧副统一按 M3×6 行程核算：通孔侧耳板 ≤2.0 mm、螺母/铜柱侧预埋，肘节锁紧用 M3×8 双通铜柱作 barrel。
- 铰链销 Ø8 为打印压配销（整合在 P5/P4 配合中），磨损后可升级 M8 螺栓。

关键计算结果（估计值，实测后更新）：

- 倾覆：M_ot = 0.409 N·m；干沙方案底座 0.92 kg、安全系数 1.84（**不满足 ≥2**）；钢砂方案 2.51 kg、安全系数 5.0（通过）。**配重因此冻结为钢砂/钢珠 ≥900 g**，干沙仅允许在通过倾覆实测后使用。
- 斜梁挠度估计：2.5 N 验收载荷下约 0.54 mm（限值 3 mm，余量充足；等效悬臂模型，实测验收为准）。
- 镜头高度链：铰链 219 -> 插榫 -> 叉耳槽底 139 -> 板底 124 -> 镜头 364.9 mm（在 364±20 内）。

打印前必须先打 P9 配合试片验证本机补偿（详见 `mechanism/camera_stand/README.md`）。

## 明确不做

- 不做电动调节、不做高度电动升降。
- 不在支架内走 220 V 或大电流线路。
- 不依赖胶粘作为最终固定方式。
- ACT 相关文档已废弃，本设计不涉及任何学习类组件。
