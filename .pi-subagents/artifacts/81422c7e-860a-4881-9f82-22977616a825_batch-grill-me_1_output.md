## 1. 问题清单（按任务要求的 7 类组织，全局编号，附推荐）

### 类别 A：锁什么姿态

**Q1（P0 根因，先于一切）"锁死"的基准量与符号修复落点？**
已知 FK yaw=pan+roll 与实测相反，且现状靠调用点 `2Δpan−Δyaw` 补偿（F4）。roll≠0 时若锁错基准，锁定值本身以 2×roll 漂移。
- **A（推荐）**：锁**物理 yaw**（碎片世界系朝向），并把符号修进模型层（标定 `joint_directions[4]` −1→+1 或 FK 改 yaw=pan−roll），拆除调用点补丁，全链路一种约定。
- B：锁"FK 报告 yaw"，保留调用点补丁——仅在 wrist_roll 恒 0 的工况成立，与"锁死框架"目标冲突。
- C：运行时方向自适应辨识——风险最高，不建议进竞赛代码。
- 附带确认：现场"相反"的具体实验现象（roll 命令 +10° 时物理 yaw 实测 −10°？）；修符号后 Homing_Offset=1400 与逻辑零位登记是否需重做。

**Q2 锁定的自由度组合？**
- A：仅锁 yaw，pitch 由任务逐段给定（现状）。
- **B（推荐）**：yaw+pitch 双锁——搬运段 pitch 恒定垂直向下、yaw 恒定；F10 表明这就是 5 轴臂可定义的全部姿态。
- C：按阶段变 pitch（如 PREGRASP 段缓降俯仰）。

**Q3 搬运段 pitch 锁定值？**
- **A（推荐）**：命令 −87.5°（现精确模式命令值，实测负载 −90.03°，F7），与已验收证据一致。
- B：命令直取 −90°——需先验证读回偏差与奇异邻域行为。
- C：逐碎片/逐阶段可配。

### 类别 B：何时锁

**Q4（P0）锁定区间与"目标上方原地旋转"的去留？**
- A：**抓取前已转到最终 yaw，全程零旋转**（PICK 吸合→PLACE 释放 yaw/pitch 恒定）——最贴合"锁死"字面，但要求抓取姿态=放置姿态，可能增加抓取难度。
- **B（推荐）**：分段锁——搬运段（SAFE 高度）锁"源 yaw+pitch"，到达目标上方后保留原地旋转动作（F5 现状的显式化），垂直段再锁目标 yaw。时间代价最小、与现有证据兼容。
- C：仅最后 30mm 垂直段锁，其余段自由插值——最小改动但名不副实。

**Q5 用户说的"抓取最后 30mm 垂直"是否即现有 `vertical_approach_mm=30.0`（F6）？**
- **A（推荐）**：是，PICK/PLACE 共用 30mm 保持冻结。
- B：PICK/PLACE 拆分参数（PLACE 可能需更大值避让已放碎片）。
- C：需现场重测——注意 PREGRASP=20mm < 30mm（F9），垂直段起点高于 PREGRASP 高度，两者衔接关系需现场确认。

### 类别 C：允许的等价角/绕线

**Q6 目标 yaw 的等价角选择策略？**（单圈舵机 roll∈[−180°,180°]，F2）
- A：维持最短角（现状 `_shortest_angle_delta`，≤180°）。
- **B（推荐）**：A 之上叠加——利用 solver 已有的 `equivalent_yaws_deg`（碎片对称性），选使 wrist_roll 行程最小的等价 yaw；超限交给 pan 补偿（pan 限位 ±110°）。
- C：允许跨圈累计——单圈 STS3215 物理不可行，排除。
- 附带确认：磁吸为圆形末端时，抓取对碎片 yaw 是否无约束（仅放置需要 yaw）？equivalent_yaws 是否已按真实碎片对称性给出？

**Q7（P0）一次竞赛全程 wrist_roll 的累计净旋转预算与回零策略？**
- **A（推荐）**：每次搬运结束 roll 回到逻辑 0°（电缆零累计，代价是每次 +1 个回零动作的时间）。
- B：允许 ±180° 内漂移、软限位兜底（现状，电缆随碎片数量单调缠绕）。
- C：全程计数，超阈值（如累计 ±540°）插入维护回零。
- 附带确认：F3——"J5 限制线缆扭转"在改装放宽到 ±180° 后**是否仍然成立**？磁吸线缆在腕部的实际走线路径。

### 类别 D：电缆/机械限位

**Q8 J5 真实可用物理行程的现场边界？**
- A：信任舵机寄存器 0..4095 ticks=360.4°（标定现有依据，F2）。
- **B（推荐）**：现场重新实测 ±180° 两端——改装后机械零位登记为逻辑 0°，但两端是否有线束张力/刮擦**无证据**；在实测前软限位临时内缩（如 ±150°）。
- C：直接加装机械止挡。

**Q9 限位的保护语义？**
- **A（推荐）**：维持现状——软限位仅规划层拦截（validate_joints + 全路径预检，F8），物理端点依赖舵机自身 Min/Max Position Limit；需现场确认舵机寄存器值与标定登记一致且未被后续改动。
- B：增加独立硬保护（止挡/限位开关）。

### 类别 E：安全失败语义

**Q10 搬运中读回发现 yaw/pitch 偏离锁定值超阈值时？**
- **A（推荐）**：fail-closed——停当前段、磁吸保持通电、进 RECOVERY/上报（与 F8 现有 MotionResult 语义一致）。
- B：原地重收敛 1 次再判失败（需定义重试次数与超时）。
- C：仅记录继续——违背锁死目的，排除。
- 附带确认：监控判据用多样本稳定读回（F7 明确 5°/单样本禁用于最终判定），建议初值 yaw≤2°、pitch≤2°，是否认可？

**Q11 ROBOT_COMM_TIMEOUT / ESTOP / 掉电时的磁吸与姿态语义？**
- **A（推荐）**：磁吸保持通电、臂就地停——碎片不掉落优先；悬于已放碎片上方时断电更糟。
- B：磁吸断电——仅空载回程可接受。
- 附带确认：F9 的磁吸连续通电能力 UNKNOWN 是否允许就这样进竞赛；单圈绝对编码器 + Homing_Offset 登记后，逻辑 0° 跨重启是否保持（重启后锁定基准是否可信）。

**Q12 目标 yaw 所需 roll 越界（或路径中点越界）时？**
- A：规划期 SAFETY_REJECTED，交由 solver 换等价 yaw（现状，F8）。
- **B（推荐）**：先自动尝试"等价 yaw + pan 补偿 + 拆段原地旋转"（F5 已有拆段机制），全部无解才 REJECT——减少竞赛中的人工介入。
- C：放宽 max_joint_step 强行通过——排除。

### 类别 F：速度/精度

**Q13 锁定段的速度档位与时间预算？**
- A：搬运全程精确模式参数（P=24/Acc=30，F7）——最稳但慢。
- **B（推荐）**：搬运巡航 HOLDING_SLOW，仅原地旋转段与垂直 30mm 段切精确模式/LOCAL_POLICY。
- C：按路径长度自适应。
- 附带确认：竞赛计时约束下，姿态锁死引入的额外原地旋转/回零时间，每件碎片允许增加多少秒？

**Q14 "锁死"的量化指标定义？**
- **A（推荐）**：段内读回统计 yaw 漂移 ≤2°、pitch 漂移 ≤2°——与标定 XY RMS 2.48mm 的精度相称（F2 quality）。
- B：≤1° 更严——可能超出 FK 精度与舵机回差，需先验证。
- C：结果导向——以放置后碎片角度误差（视觉检测分辨率）为准，不监控过程。
- 附带确认：漂移是相对**段首实测值**还是**命令值**（磁吸吸合瞬间可能存在姿态扰动）。

### 类别 G：测试验收

**Q15 最小验收场景集？**
- **A（推荐）**：空载全程锁 yaw/pitch 巡航 + 四象限极端 pan 位 + 最大 Δyaw=180° 搬运 → 带真实碎片重复 → 4 片拼装全流程回归（已有基线）。
- B：仅全流程回归（覆盖不足，符号/绕线问题可能漏检）。
- 附带确认：证据形式沿用 `calibration/evidence/<日期>/README.md` + SHA256 证据链？

**Q16 符号修复（Q1）后的回归证据范围？**
- A：仅 wrist_roll 单轴方向扫描（±10° 物理 yaw 响应）——最小集。
- **B（推荐）**：A + 4 点 holdout FK 重测，维持 accepted 标定的质量门槛（现状 holdout XY RMS 2.48mm/max 3.41mm）。
- C：全量重标定（8 fit + 4 holdout）——仅在 Q1 选择改 zero offset/标定文件时必要。

**Q17 现场验收的动作权限边界？**
- A：允许空载实机扫描，磁吸不得吸碎片。
- B：允许带碎片实测。
- C：仅 shadow/dry-run。
