研究完成，报告已写入指定输出路径。核心结论：

1. **±180° 发散是角度表示问题**：ROS `angles` 包的 `shortest_angular_distance`（一行公式）+ JTC 的逐段 wraparound 规则是最小修复，直接对应本项目 2026-08-01 的 wrist_roll 事故。
2. **姿态锁死**：MoveIt 官方语义为 `OrientationConstraint`（放开 z 轴容差、锁 x/y），legacy `computeCartesianPath` 被维护方明确劝退；本项目 pitch=−90° + 标量 yaw 的场景只需 O(1) 路点断言，不需要完整 SO(3)/OMPL 流形规划。
3. **Pi 轻量栈**：角度解包 + 连续展开/折回 + 姿态锁断言 + Ruckig（pip、无 ROS、微秒级解析 OTG）即可；MoveIt/OMPL/Drake/Pinocchio 全栈均判定为不适用（重量 + 非确定性）。
